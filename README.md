# 🎵 YouTube Music Desktop — Official Releases

Offizielles Release-Repository und Update-Feed für **YouTube Music Desktop Client**.

---

## 📥 Downloads

Die neuesten Binärdateien und Installer findest du unter:
👉 **[Releases](https://github.com/mishalng/youtube-music-releases/releases/latest)**

* **Linux:** `YouTubeMusic-Linux-Installer.zip` oder `youtube-music.py`
* **Windows:** `YouTubeMusic-Windows-Portable.zip` / `YouTubeMusic-Setup.exe`

## 🔄 Automatischer Update-Feed (`latest.json`)

Die App prüft Aktualisierungen vollautomatisch über:
`https://raw.githubusercontent.com/mishalng/youtube-music-releases/main/latest.json`

Jeder Release enthält:
* Versionsnummer
* Changelog (Deutsch & Englisch)
* SHA-256 Prüfsummen für alle Pakete
